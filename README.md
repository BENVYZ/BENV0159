# Python Data Analysis Tutorials

This repository contains materials for an 8-week beginner-friendly Python tutorial.

The course introduces students to the basic workflow of using Python for data analysis, including installing packages, importing datasets, understanding pandas DataFrames, selecting data, merging datasets, visualising data, and preparing for simple machine learning tasks.

## Repository Structure

```text
python-course-8-weeks/
├── README.md
├── requirements.txt
├── .gitignore
├── week_01/
├── week_02/
├── week_03/
├── week_04/
├── week_05/
├── week_06/
├── week_07/
└── week_08/
```

Each weekly folder can contain:

- tutorial notebooks
- exercise notebooks
- datasets
- short notes

## How to Use This Repository

1. Download or clone this repository.
2. Install the required packages.
3. Open the weekly notebook in Jupyter Notebook, JupyterLab, VS Code, or Google Colab.
4. Follow the tutorial and complete the exercises.

## Install Required Packages

Using pip:

```bash
pip install -r requirements.txt
```

Using conda:

```bash
conda install pandas numpy matplotlib seaborn scikit-learn jupyter
```

## Weekly Topics

1. Week 01: Python packages, CSV import, and pandas DataFrame basics
2. Week 02: Data selection, filtering, and basic data checking
3. Week 03: Data cleaning and missing values
4. Week 04: Data grouping and summary statistics
5. Week 05: Data visualisation with matplotlib and seaborn
6. Week 06: Merging datasets and working with multiple tables
7. Week 07: Introduction to machine learning with scikit-learn
8. Week 08: Course project and review
